Connexion à Supabase requise

Cette application a besoin de ta base Supabase pour partager les données entre les 14 utilisateurs. Ouvre index.html et renseigne, tout en haut du script, ces deux valeurs :

const SUPABASE_URL = "https://xxxx.supabase.co";
const SUPABASE_ANON_KEY = "eyJ...";

Tu les trouves dans Supabase > Project Settings > API (Project URL et clé anon public). Enregistre, recharge la page.

⚠️ Le SDK Supabase n'a pas pu se charger — vérifie ta connexion réseau puis recharge.
